# 儿童视功能训练 App 完整方案（跨端）

## 1. 产品目标

构建一个面向 6-15 岁中小学生的训练平台，支持电脑、Web、平板，覆盖以下核心场景：

1. 立体视训练（双眼融合、深度判断）
2. 弱视辅助训练（辨识、追踪、注意力）
3. 远近调节与用眼习惯训练（辅助管理，不替代临床诊断）
4. 家长、老师、治疗师、运营人员多角色协作

> 医疗边界：本系统用于训练辅助与依从性管理，不用于替代临床诊断或处方。

## 2. 角色与端

- 学生端（Flutter）：训练关卡、闯关激励、提醒
- 家长端（Flutter/Web）：计划管理、报告查看、提醒设置
- 教师/治疗师端（Web）：批量分配方案、班级追踪
- 管理后台（Web）：内容管理、用户管理、审核发布、数据看板

## 3. 总体技术架构

- **客户端**：Flutter（主）
- **网关层**：Nginx / API Gateway
- **业务层**：
  - Java Spring Boot：用户、权限、训练策略、报告、运营
  - Go 服务：高频训练日志接入、实时统计
- **数据层**：PostgreSQL + Redis + 对象存储（MinIO/OSS）
- **部署**：Docker Compose（MVP）→ Kubernetes（规模化）

## 4. 功能模块（MVP）

### 4.1 学生端

- 今日任务卡片（单主任务，降低选择负担）
- 训练流程：热身 → 3~5 个小游戏关卡 → 成绩反馈
- 奖励系统：星星、勋章、连续签到
- 护眼提醒：定时休息、姿势提示

### 4.2 家长端

- 训练完成率、准确率、时长趋势
- 一键调整训练时段（晚间/周末）
- 未完成提醒策略（轻提醒/强提醒）

### 4.3 教师/治疗师端

- 分组管理（班级/机构）
- 训练处方模板分发
- 低依从学生筛选与干预

### 4.4 运营后台

- 内容管理：关卡、素材、文案、语音
- 审核流程：编辑→医学顾问→发布
- 数据看板：留存、完课率、活跃度、异常指标

## 5. 视觉与交互规范（儿童友好）

1. 大按钮：主按钮高度 ≥56px，触达区域 ≥48x48
2. 卡通风：圆角、大色块、友好角色引导
3. 文案短句：每屏最多 1 个主要目标
4. 强反馈：语音 + 动效 + 星级奖励
5. 可访问性：高对比模式、色弱友好、可关闭动画

## 6. 训练业务闭环

1. 建档：家长注册 → 学生档案（年龄、年级、基础视力信息）
2. 初评：问卷 + 基础互动任务
3. 计划：系统生成首周训练计划（每天 10~20 分钟）
4. 执行：按天训练并自动记录
5. 复盘：周报/月报 + 建议调整
6. 干预：连续 2 天未完成自动简化任务包

## 7. 非功能需求

- 安全：HTTPS、敏感字段加密、审计日志
- 隐私：未成年人数据最小化与可删除
- 稳定：核心接口 P95 < 300ms（MVP 可放宽）
- 可观测性：日志、指标、告警

## 8. 里程碑（12 周）

- W1-W2：需求冻结、交互原型、UI 规范
- W3-W5：学生端 + 用户/训练核心服务
- W6-W8：家长端 + 报告 + 管理后台
- W9-W10：联调、灰度、指标体系
- W11-W12：试点上线 + 迭代
