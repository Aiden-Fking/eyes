# 操作流程与管理流程（完整）

## 1. 用户操作流程（学生/家长）

### 1.1 首次开通

1. 家长手机号注册
2. 填写学生信息（年龄、年级、佩镜情况）
3. 选择训练目标（立体视/弱视辅助/用眼习惯）
4. 系统生成默认训练计划
5. 家长确认并开启提醒

### 1.2 每日训练

1. 到点提醒
2. 点击“开始今日训练”
3. 热身 30 秒
4. 完成 3~5 个关卡
5. 查看“今日成绩卡”
6. 家长端收到完成通知

### 1.3 异常流程

- 中途退出：自动保存进度，30 分钟内可续练
- 连续未完成：触发更短训练包 + 家长提醒
- 疲劳上报：降级训练难度，建议休息

## 2. 教师/治疗师操作流程

1. 创建班级/分组
2. 批量导入学生（需家长授权）
3. 套用训练模板（7 天或 14 天）
4. 每周查看依从性榜单与风险名单
5. 对风险名单下发干预方案

## 3. 内容管理流程

1. 内容编辑上传素材
2. 医学顾问审核（适龄性、风险提示）
3. 通过后灰度发布（10%）
4. 观察 48 小时指标
5. 全量发布或回滚

## 4. 运营管理流程

- 周活动：主题挑战（如“护眼连胜周”）
- 用户激励：勋章、积分、连胜奖励
- 数据复盘：
  - D1/D7 留存
  - 周完成率
  - 平均训练时长
  - 关卡失败率

## 5. 权限与审计管理

- 学生：仅可访问自己的训练任务
- 家长：可访问孩子训练数据与提醒配置
- 教师/治疗师：仅访问授权学生群组
- 运营：内容与活动管理
- 超管：系统配置、用户封禁、审计查询

## 6. 质量与应急机制

- 每月医学内容复审
- 关键接口异常告警（5xx、超时、错误率）
- 紧急回滚策略：配置开关 + 版本回退
- SLA：工作日 24 小时内首响
